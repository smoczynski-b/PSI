## Citation policy

When a Zenodo record corresponds to the work being cited, prefer the Zenodo DOI because it identifies a fixed archived research object.

Use the GitHub repository when referring to the current evolving public implementation, documentation, examples or later corrections that are not yet represented by a fixed Zenodo record.

## Repository relationship

The intended publication chain is:

```text
working research corpus
        ↓
public PSI repository
        ↓
versioned release
        ↓
Zenodo archival record + DOI
```

This separation is deliberate: a citable archival object should remain fixed, while the public research repository may continue to evolve.

## Metadata note

The record identifiers above are linked from the author's existing Zenodo deposits. Titles, versions and detailed bibliographic metadata should be taken from the corresponding Zenodo records themselves rather than duplicated manually here when they may change between versions.
