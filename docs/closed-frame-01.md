## 4. EXPLORE `E` — strongest useful formulation

Choose an oriented orthonormal normal pair at a base point and transport it relatively parallel around the loop.

After one circuit the returned pair differs from the initial pair by a unique element

\[
\boxed{H_\gamma\in SO(2),}
\]

which we call the normal/Bishop holonomy or return rotation.

For an initial normal basis changed by a constant rotation `R_alpha`, the return map is conjugated:

\[
H_\gamma\mapsto R_\alpha^{-1}H_\gamma R_\alpha.
\]

Since `SO(2)` is abelian,

\[
\boxed{H_\gamma\text{ is independent of the initial normal basis.}}
\]

Thus `H_gamma` is not a preferred-frame artifact.

A periodic Bishop/RMF frame exists exactly when

\[
\boxed{H_\gamma=I.}
\]

When a periodic Frenet frame exists and torsion is defined globally, the classical comparison gives, up to the sign convention for normal-plane rotation,

\[
\boxed{
H_\gamma
=R_{-\Theta_\gamma},
\qquad
\Theta_\gamma=\int_0^L\tau(s)\,ds
\pmod{2\pi}.
}
\]

Hence

\[
\boxed{
\text{periodic RMF}
\iff
\Theta_\gamma\in2\pi\mathbb Z.
}
\]

This is classical and is not a PSI theorem.

## 6. A1 — mathematical audit

### 6.1 Periodicity

By definition of the return map, an initial oriented normal pair `(N1(0),N2(0))` returns as

\[
(N_1(L),N_2(L))=(N_1(0),N_2(0))H_\gamma.
\]

Hence the transported frame is periodic iff `H_gamma=I`.

### 6.2 Frenet comparison

On the positive-curvature subdomain, write the Bishop normal pair as a rotation of the Frenet normal/binormal pair by an angle `theta` satisfying, in the chosen convention,

\[
\theta'(s)=-\tau(s).
\]

Therefore

\[
\theta(L)-\theta(0)=-\int_0^L\tau(s)\,ds,
\]

and the return angle is total torsion modulo `2π`.

Brander–Gravesen state the corresponding classical criterion: for a closed curve with periodic binormal, a rotation-minimizing frame is periodic iff the total torsion is an integer multiple of `2π`.

### 6.3 Generality boundary

If curvature vanishes, the Frenet formula may cease to be legal, but `H_gamma` remains definable through Bishop/normal transport under the weaker regularity needed for that transport.

So total torsion is a convenient coordinate for the holonomy on the Frenet-valid subdomain; it is not the definition of the global datum.

## 7. Concrete pressure witness

For a reproducible closed analytic example define the `(2,3)` torus-knot curve

\[
\gamma(t)
=
\left(
\left(2+\tfrac12\cos3t\right)\cos2t,
\left(2+\tfrac12\cos3t\right)\sin2t,
\tfrac12\sin3t
\right),
\quad 0\le t\le2\pi.
\]

Let

\[
c=\cos3t.
\]

Its speed satisfies

\[
\|\dot\gamma\|^2
=
\frac{4c^2+32c+73}{4}
\ge
\frac{45}{4}>0.
\]

Moreover

\[
\|\dot\gamma\times\ddot\gamma\|^2
=
\frac{
32809+44608c+13308c^2+1024c^3-80c^4
}{16}.
\]

The numerator is increasing on `[-1,1]` and its minimum is `405`, so

\[
\kappa(t)>0
\quad\forall t.
\]

A high-precision numerical integration of the exact torsion formula gives

\[
\Theta_\gamma
=\int\tau\,ds
\approx
0.7970800677641300\;\text{rad}.
\]

Hence this computational witness has a nontrivial RMF/Bishop return rotation.

**Status of the numeric value:** `MODEL / REGRESSION WITNESS`, not a new theorem and not needed for the general classical existence claim. Classical literature independently exhibits closed curves with prescribed/nontrivial total torsion.

## 8. E_fals — attacks

### X1 — “constant gauge can remove holonomy”

FAIL.

Constant `SO(2)` gauge only conjugates the return map; in the abelian normal-plane group it leaves `H_gamma` unchanged.

### X2 — “allow an arbitrary varying gauge and make the frame periodic”

This changes the contract.

A nonperiodic gauge on the cut interval is not a well-defined gauge transformation on the closed base `S^1`. A periodic varying gauge changes the local connection expression but preserves the holonomy conjugacy class.

### X3 — “nontrivial holonomy means a new catalogue object was born”

FAIL under the snapshot.

The underlying closed curve has not changed. Holonomy is produced by transporting the existing frame data around a nontrivial loop.

### X4 — “the interval MINI theorem was false”

FAIL.

The interval theorem never claimed periodic closure. CLOSED-FRAME is a global extension boundary, not a counterexample inside the interval contract.

### X5 — “holonomy is irrelevant because it is only representation”

Too strong.

It is irrelevant **only for tasks that do not ask about periodic framing/orientation**. For a material-frame or periodic-orientation task it is task-relevant.

Thus relevance is relative to `T`.
