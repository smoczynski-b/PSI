## Volume I — Foundations

Purpose: define the PSI problem before presenting derived theorems or laboratories.

1. Contract and typing
   - candidate space after gauge;
   - observation map;
   - compatibility relation;
   - task observables;
   - admissible dynamics / transports.
2. Observation is not object
   - observation pipeline;
   - compatible fibre;
   - catalog adequacy before identification.
3. Task-relative distinction
   - task closure;
   - exact equivalence kernels;
   - task equivalence;
   - task quotient.
4. Logical discipline
   - catalog → fibre → local → global → protocol;
   - class before representative;
   - new primitive only when semantic role changes.
5. Epistemic boundaries
   - representation ≠ represented object;
   - source/provenance requirements;
   - dual-use publication gate;
   - limits of automated interpretation.

Historical TAO/SMOK/STPψ ontology does not appear here as current foundation; it belongs to Volume IV.

1. Elementary quotient layer
   - exact decidability criterion;

   - global task sufficiency;

2. Information order
   - refinement/coarsening relations;
   - monotonicity statements where proved.
3. Dynamic quotients
   - deterministic quotient criterion;
   - memory/representation conditions;
   - lumpability bridge under explicit stochastic hypotheses.
4. Higher / structured fibres

6. Factorization architecture
   - PSI-CAT;

7. Classical comparison
   - deterministic congruence;
   - Nerode realization;
   - lumpability;
   - bisimulation;
   - partition refinement.

1. PHISICA / operator laboratories
   - domain-first operator reductions;
   - spectral/resolvent/pseudospectral hierarchy;
   - HCube.
2. LAZARUS
   - protocol under limited observation;
   - recovery ladder;
   - decision ledger;
   - same fibre / different agency cases.
3. Games and finite systems
   - chess/Go;

   - finite-state quotient tests.
4. Agents
   - AGENT SPEC ≠ LIVE STATE;

5. PSI-FORUM
   - proof/counterexample/unresolved/test exchange;

6. Cultural laboratories
