# PSI Publication Policy

Working state and publication state are distinct.

Internal material is not public merely because it is scientifically useful, version-controlled or technically valid. Publication requires an explicit scope and a disclosure decision:

```text
PUBLIC | REVIEW | WITHHOLD
```

A public release should contain only the files or fragments needed for its stated purpose. Conversation exports, agent instructions, telemetry, private drafts, account data and credentials default to `REVIEW` or `WITHHOLD`.

Public-facing prose, release notes, PR descriptions and public commit messages use English. Quotations, mathematical symbols and technical identifiers preserve their source form.

Source provenance and epistemic status must survive redaction.

The following implications are invalid without separate evidence:

```text
THEOREM PASS      -> PUBLICATION AUTHORIZED
TEST PASS         -> SYSTEM PASS
CONTROL PASS      -> THEOREM PASS
PUBLICATION PASS  -> USER COMPREHENSION
```

Public history is provenance. Removing a current file or changing future workflow does not erase previously published copies. History rewriting is not the default remedy for editorial or language cleanup.
