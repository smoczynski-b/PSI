## 2. Reprezentacja nie jest reprezentowanym obiektem

Jeżeli

\[
\rho:\Omega_c\to Z,
\]

to \(\rho(x)\) jest reprezentacją \(x\), nie samym \(x\). To samo dotyczy obserwacji, włókna i klasy zadaniowej.

\[
\boxed{
\text{REPREZENTACJA}
\neq
\text{REPREZENTOWANY OBIEKT}.
}
\]

W szczególności klasa

\[
[x]_{\mathcal T,c}
\]

nie jest twierdzeniem ontologicznym o identyczności jej reprezentantów. Oznacza wyłącznie brak potrzeby ich dalszego rozróżniania przez zadanie i kontrakt.

---

## 3. Nieobserwowane nie znaczy zero

Jeżeli kanał obserwacji nie wyznacza pewnej wielkości, nie ma podstaw do przypisania jej wartości zerowej.

\[
\boxed{
\text{NIEOBSERWOWANE}
\neq
0.
}
\]

Analogicznie:

\[
\boxed{
\mathrm{UNRESOLVED}
\neq
\mathrm{NEGATED}.
}
\]

Brak prawa do potwierdzenia warunku nie jest prawem do potwierdzenia jego negacji.

---

## 4. Dwa porządki pozostają rozdzielone

Kanoniczny porządek identyfikacji brzmi:

\[
\boxed{
\text{ADEKWATNOŚĆ KATALOGU}
\to
\text{WŁÓKNO}
\to
\text{ID LOKALNA}
\to
\text{ID GLOBALNA}
\to
\text{REDESIGN / REFINACJA PROTOKOŁU}.
}
\]

Osobno, gdy sformułowano konkretny wniosek, bada się jego jakość:

\[
\boxed{
\mathrm{ID}_{exact}
\not\Rightarrow
\mathrm{ID}_{stable},
\qquad
\mathrm{ID}_{stable}
\not\Rightarrow
\mathrm{CONF}_{1-\alpha}.
}
\]

Nie zapisujemy tych pojęć jako łańcucha „nierówności”. Są to **odrębne pytania o odmiennych warunkach licencji**. Drugi porządek nie jest przedłużeniem pierwszego.

## 5. PSI-ID nie jest PSI-CAT

\[
\boxed{
\mathrm{PSI\!-ID}
\neq
\mathrm{PSI\!-CAT}.
}
\]

PSI-ID pyta o rozróżnienia uzasadnione wewnątrz ustalonego katalogu. PSI-CAT pyta, czy katalog należy zmienić i jaką klasę zmiany uzasadnia protokół.

Puste włókno wskazuje niespójność bieżącego pakietu, ale samo nie identyfikuje nowego katalogu. Dobra identyfikowalność w katalogu nie dowodzi jego adekwatności.

---

## 6. Równoważność realizacyjna nie jest recodem behawioralnym

Równoważność realizacyjna usuwa różnice uznane przez kontrakt za prezentacyjne lub izomorficzne. Recode behawioralny może zachowywać określone zachowanie przy przejściu do realizacji nieizomorficznej.

\[
\boxed{
\text{realization equivalence}
\neq
\text{behavioural recoding}.
}
\]

Recode jednokierunkowy nie musi być równoważnością. W PSI-FACT quotient przez gauge jest legalny tylko wtedy, gdy odpowiednią równoważność ustanawia kontrakt.

---

## 7. Symetria nie jest automatycznie gauge

Z istnienia działania grupy lub grupoidu nie wynika prawo do quotientu w konkretnym problemie obserwacyjnym.

\[
\boxed{
\text{symetria geometryczna}
\not\Rightarrow
\text{legalny gauge ustalonego włókna danych}.
}
\]

Pierwsza bramka jest zadaniowa:

\[
\ker_{\rm eq}q\subseteq E_{\mathcal T,c}.
\]

Druga jest kontraktowa: typy, dziedziny, działanie gauge, zgodność obserwacji, interfejs i pozostałe wymagania protokołu muszą również być legalne.

---

## 8. Zakaz `candidate stuffing`

Nie wolno dowodzić wystarczalności CORE5 przez arbitralne wpisywanie brakującej odpowiedzi do przestrzeni kandydatów.

\[
\boxed{
\text{candidate stuffing}
\neq
\text{dowód wystarczalności CORE5}.
}
\]

Rozszerzenie \(\Omega_c\) jest legalne tylko wtedy, gdy nowa informacja naprawdę pełni rolę kandydata/realizacji. Informacji należącej do obserwacji, historii protokołu, zadania, zgodności lub reguły aktualizacji nie wolno przemycać do \(\Omega_c\) bez jawnej zmiany kontraktu.

## 9. Nowy prymityw wymaga nowej roli semantycznej

CORE5 pozostaje

\[
\mathfrak P_c=
(\Omega_c,\Psi_c,\mathcal K_c,\mathscr O_{\mathcal T,c},\delta_c).

Bieżąca zasada wzrostu teorii brzmi:

\[
\boxed{
\text{nowy prymityw dopuszczamy dopiero wtedy,

}
\]

Bogatsza reprezentacja, nowy parametr, nowy model danych albo bardziej złożony quotient nie są jeszcze nowym prymitywem, jeśli mieszczą się w istniejących rolach bez zmiany ich znaczenia.

Nie jest to twierdzenie o uniwersalnej kompletności CORE5. Jest to falsyfikowalna dyscyplina wzrostu teorii.
