# PSI — public model-to-model interoperability note

Status: PUBLIC INTEROPERABILITY SPECIFICATION.

This note describes how PSI material that is deliberately released for model-to-model reuse should preserve epistemic status. It does **not** expose or govern private handoffs.

When relevant, distinguish `CONTEXT`, `KNOWN`, `CLAIM`, `EVIDENCE`, `INFERENCE`, `HYPOTHESIS`, `UNCERTAINTY`, and `NEXT`.

For mathematics prefer:

\[
\text{definition}\to\text{type/domain}\to\text{assumptions}\to\text{statement}\to\text{proof/status}.
\]

A transferred conclusion must not silently become a transferred fact. The receiving model preserves the supplied status unless it performs an explicit new verification.

Public interoperability text is normally English. Mathematical symbols, quotations and protocol/code identifiers retain their source form. Private handoff artifacts require a separate disclosure decision before publication.
