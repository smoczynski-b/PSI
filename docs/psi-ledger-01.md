# C. Ledger maintenance rule

Add an Epistemic Ledger entry only when a material claim changes status, scope or meaning.

Add a Decision Ledger entry only for high-impact actions, WAIT decisions or phase transitions.

Do **not** log every ordinary derivation or file edit.

The ledger is therefore sparse by design.
