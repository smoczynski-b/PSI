# 1. Issue

The migration audit and the first prose version of III.3 used a Green–Lagrange boundary form written in the convention in which the Hilbert inner product is linear in the first argument.

However III.2 explicitly fixes

\[
\boxed{
\langle f,g\rangle_\rho
=\int \overline f\,g\,\rho\,d\lambda,
}
\]

which is conjugate-linear in the first argument and linear in the second.

The whole-block crosscheck therefore found a convention mismatch.

---

# 2. Correct boundary form

For

\[
\tau u
=-\frac1{2\rho}(pu')'+Vu,
\qquad p=\rho B,
\]

and the III.2 inner-product convention,

\[
\boxed{
\langle H_{\max}u,v\rangle_\rho
-
\langle u,H_{\max}v\rangle_\rho
=
\frac12
\left[
\overline u\,(pv')
-
\overline{pu'}\,v
\right]_a^b.
}
\]

The corresponding endpoint sesquilinear form is

\[
\boxed{
\omega((x_1,x_2),(y_1,y_2))
=
\overline{x_1}y_2-\overline{x_2}y_1.
}
\]

---

# 3. Robin subspaces

A separated real Robin relation

\[
\cos\theta\,x_1+\sin\theta\,x_2=0
\]

selects a one-dimensional **complex** subspace of \(\mathbb C^2\), generated by a real vector. It is maximal isotropic for the endpoint Green–Lagrange form.

The former phrase “one-dimensional real line” is therefore withdrawn.

\[
\boxed{
\text{BOUNDARY-FORM CONVENTION ERRATA}

}
\]

The physical III.3 prose has been corrected directly.
