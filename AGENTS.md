# PSI — public repository agent guidance

This file governs work intended for the **public repository surface**. It does not select or expose the private research queue.

- Preserve CORE5 and CANON-03 unless an accepted typed counterexample requires otherwise.
- Use the Bronsztejn gate for mathematical changes: object → type/domain → conditions → claimed quantity → proof/test.
- Preserve provenance and epistemic status. Received or historical text is not automatically a verified current claim.
- Do not infer a private NEXT from historical audit files, experiment notes or old handoffs.
- Do not hard-code current private work selection in this file.
- Before any public transmission, apply [Publication Policy](docs/publication-policy.md) and [source governance](docs/source-governance-01.md).
- Separate validation from disclosure: `VALIDATE -> DISCLOSURE GATE -> PUBLISH`.
- A coherent public change should normally be reviewable as one unit. Never force-push as a routine repair.
- Do not publish conversation exports, private agent instructions, telemetry, account data, credentials or private drafts unless their exact disclosure scope has been explicitly approved.

Public control checks are organizational. They do not certify theorem truth, deployment state or user understanding.
