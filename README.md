# PSI

It asks:

> What are we entitled to conclude from what we can actually observe?

\[
F(Y)=\Psi^{-1}(\mathcal K^Y).
\]

\[
|q_{\mathcal T}(F(Y))|=1
\iff
F(Y)\neq\varnothing
\land
F(Y)^2\subseteq E_{\mathcal T}.
\]
